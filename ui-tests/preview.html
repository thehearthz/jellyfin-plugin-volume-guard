Volume Guard

Level audio on the Jellyfin server and keep your standard Moonfin player.

Administrator access is required to load or change these controls.

Server processing converts audio before sending it to your player. Video can remain unchanged where compatible. It uses server resources and replaces the original audio bitstream. Changes apply to new playback unless automatic switching is enabled below. This plugin cannot add buttons to Moonfin's player or preview screens.

Listening controls

Use this master switch to turn Volume Guard on or off. It applies to all users. Start new playback to apply a change, or enable automatic switching below.

Turn this on to use stock Moonfin without a companion app. It is off until you opt in. When enabled with an active listening mode, playback negotiation requests audio conversion instead of Direct Play; your user account must allow audio transcoding. Direct playback outside that negotiation path bypasses the effect.

Choose Off for normal audio, Balanced for everyday leveling, Night for quieter listening, or Auto to follow your schedule. The mode is chosen when a new audio conversion starts.

Balanced levels quieter passages gently. Night uses a quieter target and a lower peak ceiling.

Use 0 to leave dialogue unchanged. Boosts speech frequencies and the center channel where available; it cannot separate voices from music in a mixed soundtrack. The peak limiter remains active.

Device settings

Devices without an override follow the listening controls above. An override cannot enable processing when the master switch or server processing is off. Refresh playback status to find connected devices, or enter a Jellyfin device ID manually.

Night schedule

When a schedule or saved setting changes the active mode, request a brief playback restart on compatible clients. A restart may interrupt playback; clients that cannot restart must start new playback manually. Check playback status for the result.

For example, America/New_York, Europe/London, or UTC. Daylight saving follows this time zone.

Days are the days each window starts. Friday 22:00 to 07:00 ends Saturday morning. End times are exclusive; equal start and end times are not allowed.

No night windows. Auto will use the daytime mode.

Loudness analysis

Run the Volume Guard loudness analysis task in Jellyfin Dashboard → Scheduled Tasks to measure supported local files. Analysis reads the audio and uses server resources; it does not change your media files. Cached measurements improve consistency between titles. Live TV and titles without a measurement continue using real-time leveling.

A lower number is quieter. This target guides measured title gain; compression and limiting still affect the final output.

Advanced audio profiles

These are signal levels, not a room volume limit or measured LUFS loudness. Server audio is encoded after processing, so the final decoded peak can differ from the filter ceiling. Higher maximum gain can raise background noise. Keep the target at or below the peak ceiling.
